# StoreKeeper — App Store Listing

## App Name

StoreKeeper — Supplier Catalog Importer

## Tagline

Upload supplier spreadsheets, review mappings, import new products.

## Description

StoreKeeper makes it easy to turn supplier catalog files into Shopify
product listings. Upload a CSV or XLSX file from your supplier, and
StoreKeeper automatically detects columns, maps them to Shopify product
fields, and lets you review everything before importing.

**Key features:**

- **Smart column detection** — Automatically recognizes common supplier
  headers like SKU, Price, Description, and 100+ aliases
- **Review before you import** — See every product, variant, and image
  before anything touches your store
- **Validation built in** — Catches missing titles, duplicate SKUs,
  suspicious prices, and other issues before import
- **Variant support** — Groups flat spreadsheet rows into products with
  color, size, and other option variants
- **Duplicate detection** — Checks existing store products by SKU and
  barcode to avoid creating duplicates
- **Batch import** — Creates hundreds of products efficiently with
  automatic rate-limit handling
- **Safe and recoverable** — Every import is resumable. Failed items
  can be retried individually without re-importing everything
- **Image support** — Attach product images from supplier URLs
- **Multiple formats** — CSV (comma, tab, semicolon), XLSX, European
  number formats, Unicode characters

**How it works:**

1. Upload your supplier's CSV or XLSX file
2. Review the auto-detected column mappings
3. Fix any flagged issues
4. Preview products and confirm the import plan
5. Import to your Shopify store

StoreKeeper only creates new products. It never modifies or deletes
your existing products.
